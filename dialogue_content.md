# Dialogue Content - Studio Sim

Edit the lines below as you see fit. When you're done, give this file back and I'll update the code.

**Template variables you can use:**
- `{title}` — the painting's name
- `{artist}` — the artist's name (Steam display name)
- `{adj}` — random adjective from that character's adjective pool
- `{adj2}` — a second random adjective (different from the first)
- `{term}` — random art term from that character's term pool
- `{term2}` — a second random art term (different from the first)
- `{statement}` — the artist's statement (truncated to ~120 chars)
- `{item}` — the name of an attraction/object the visitor is looking at

# PART 1: ELEVATOR CRITICS

These are the critics who review your painting in the elevator after you ship it.
Each critique is assembled from: **Opener + Title Reaction + Visual Comment + (sometimes) Artist Comment + Statement Reaction OR No-Statement Remark + Closer**.
